杭州 5 号楼 · 第 4 层支撑布置网页源码

请先完整解压 ZIP。直接打开 work/boyue-site/out/index.html 即可离线使用。

修改网页
  work/boyue-site/stage1/ 包含网页入口 main.js、界面模板、样式、支撑计算和交互源码。
  work/boyue-site/stage1/projects/hangzhou/ 包含本版网页实际加载的杭州数据。
  work/boyue-site/ 同时保留项目已有历史源码、样例和构建产物。当前网页入口为 out/index.html。

重新生成网页
  在解压根目录运行 node build.cjs。需要 Windows x64、Node.js 和 Python 3。
  包内附本版使用的 esbuild。可用 PYTHON 环境变量指定 Python 可执行文件。
  生成的网页在 work/boyue-site/out/index.html，另存一份到 outputs/杭州5号楼_4层基本模型.html。

重新识别模型和底图（仅修改网页时可跳过）
  模型、底图、转换过的 DXF 和中间数据在 work/hangzhou-web-input/。
  hangzhou-4.step 是 5#楼（4层墙）基本层三维模型2026.8.15.STEP。
  hangzhou-input.dwg 是杭政储出[2024]32号地块项目-04地块5#楼铝模深化底图2026.08.11_t3.dwg。
  如要重新提取 STEP，请使用 Python 3.12 安装 requirements-step.txt 列出的依赖。
  以下命令均在解压根目录运行。

  python -m pip install -r work/hangzhou-web-input/requirements-step.txt
  python work/hangzhou-web-input/extract.py
  node work/hangzhou-web-input/read-cad.mjs
  node work/hangzhou-web-input/prepare-web.mjs
  node build.cjs

  read-cad.mjs 读取 reference.dxf。若更换原始 DWG，请先用 CAD 转换工具导出同名 ASCII DXF。
  prepare-web.mjs 使用 outputs/ 下随包附带的识别引擎模块，并用原始 STEP 与 DWG 计算来源指纹。
