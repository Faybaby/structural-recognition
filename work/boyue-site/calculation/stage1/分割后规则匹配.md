# 分割后自动匹配与计算（2026-11-17）

统一流程：三维分割 → 阴阳边核验 → 匹配已有情况 → 免放判断 → 梁宽/梁高/板厚向上查表 → 交点与GTT → 正式位置 → 四层实际承接长度。

- 普通梁、阳端及GL挂梁使用共同的情况匹配函数，分别保留已确认的端距规则。楼面规则及数值结果保持原样。
- 原生阴阳边优先。虚拟分界不改变原有阴阳边。企口短缝、T形接头内部缺边，不据此增加阴阳分界。
- 分割后两侧均为阳线的同宽段恢复普通梁或变宽段计算；有真实阴线且满足WN≤200的窄段继续免放。边线证据不足单列待核。
- 同一三维梁面中，同宽同类的T形分支接到真实中心线交点，随后分别计算各段GTT。与免放区域生成的交点取消，不作为锚点。
- 梁高差<100mm才考虑交点，=100mm及更大不放。真实梁梁交点可作50mm模数例外，在真实交点放支撑并特殊标注偏离量；普通补点与阳端位置仍按50mm模数。交点不位移，其他证据缺项仍待处理。
- PB012横向恢复段匹配梁情况2.2，交点(4825,8200)，几何GTT为425、1075mm。当前基准下相差25mm，按最新确认作为模数例外生成正式交点；竖向另列2400、50mm分段。
- 两模型115根三维梁，264条内部路线：255条已处理，9条待核。恢复12条原提前免放路线；正式普通梁为两模型378点、四层756实例。其中16个去重模型交点属于模数例外，图中用品红色标识，步骤和JSON/CSV均保留例外原因与偏离量。待核不当作免放，也不当作通过。
- 校验覆盖普通梁、挂梁数值回归（两组基准）、楼面结果、CAD修正版示例、免放交点、原生面与实际承接面。原表单元格、实际三维底面和向下最近承接面逐点核对通过。

原DWG、SLDPRT、原STEP几何及整楼基准未改写。网站仍用已载入原STEP快照，未重新导入后续改变的本机SLDPRT。当前只计算位置，不选固顶型号。
